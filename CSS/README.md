# CSS Learning Notes

This folder contains a collection of small CSS practice files for learning and experimenting with frontend styling.

## Overview

The examples cover core CSS topics such as selectors, box model, units, variables, responsiveness, flexbox, grid, transitions, animations, and more. Each file is a standalone HTML page that demonstrates a specific CSS concept.

## Included Topics

- Selectors and styling basics
- Box model and spacing
- Typography and text properties
- CSS units and values
- Variables and reusable values
- Flexbox and alignment
- Grid layout
- Min/max sizing
- Responsive design
- Transitions and animations
- Additional CSS patterns and utilities

## Files

- `additional.html` and `additional.css` – extra CSS practice examples
- `animations.html` – animation examples
- `box.html` and `box.css` – box model styling
- `flexbox.html` and `flexbox.css` – flex layout examples
- `flexwrapandalign.html` – wrapping and alignment practice
- `grid.html` and `grid.css` – CSS grid examples
- `min-max.html` and `min-max.css` – min/max sizing patterns
- `properties.html` and `properties.css` – CSS property demos
- `responsive.html` – responsive design examples
- `selectors.html` and `selectors.css` – selector usage
- `transition.html` – hover transitions
- `types.html` and `types.css` – CSS value types
- `units.html` and `units.css` – length and unit examples
- `universal.css` and `univesal.html` – universal selector examples
- `variables.html` and `variables.css` – CSS custom properties

## How to Use

1. Open any HTML file in a browser.
2. Review the linked CSS file to understand the styling logic.
3. Edit the CSS and refresh the page to see changes live.
4. Use these files as practice exercises for learning layout and design concepts.

## Suggested Learning Order

1. Start with selectors and basic properties
2. Learn box model and spacing
3. Practice units and variables
4. Explore flexbox and grid
5. Build responsive layouts
6. Add transitions and animations

## Notes

These files are designed mainly for learning and experimentation. They are simple, beginner-friendly examples rather than production-ready components.
