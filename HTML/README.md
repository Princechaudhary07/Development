# HTML Learning Files

This folder contains a collection of HTML practice files demonstrating various HTML concepts and elements.

## 📁 File Guide

### Basic HTML Structure
- **heading.html** - Demonstrates HTML heading tags (h1-h6) for different heading levels
- **paragraph.html** - Shows how to use paragraph tags and text content
- **heading-paragraph.html** - Combines headings and paragraphs together
- **additional.html** - Additional HTML basics and concepts

### Semantic HTML
- **semantic.html** - Demonstrates semantic HTML tags including:
  - `<header>` - Page header
  - `<main>` - Main content area
  - `<article>` - Article content
  - `<aside>` - Sidebar content
  - `<section>` - Content sections
  - `<footer>` - Page footer

### Text & Content
- **specialtags.html** - Special formatting tags (bold, italic, strong, emphasis, etc.)
- **selfclosing-tags.html** - Self-closing/void HTML tags (br, hr, img, input, etc.)

### Grouping & Containers
- **divandspan.html** - Demonstrates `<div>` and `<span>` elements for grouping content

### IDs & Attributes
- **id.html** - Shows how to use ID attributes for unique element identification
- **anchor-linking.html** - Demonstrates internal page linking with anchor tags and IDs

### Lists
- **list.html** - Shows different list types:
  - Ordered lists (ol)
  - Unordered lists (ul)
  - List items (li)

### Forms & Input
- **form.html** - Basic form structure with:
  - Input fields (email, text)
  - Text areas
  - Select dropdowns
  - Submit and reset buttons
  - Form labels
- **formsubmission.html** - Demonstrates form submission and handling
- **formValidation.html** - Form validation examples
- **checkbox.html** - Checkbox input demonstrations
- **radio.html** - Radio button input demonstrations

### Tables
- **table.html** - HTML table structure including:
  - Table headers (thead, th)
  - Table body (tbody)
  - Table footer (tfoot)
  - Table rows (tr)
  - Table cells (td)
  - Row/column spanning (rowspan, colspan)

### Media & Images
- **images.html** - Image tag demonstrations and image usage
- **svg.html** - Scalable Vector Graphics (SVG) elements
- **images/** - Folder containing image assets used in the HTML files

### Navigation & Links
- **first-page.html** - First page with navigation/linking examples
- **second-page.html** - Second page demonstrating multi-page navigation
- **wikipedia.html** - Example page linking to and referencing external content

## 🎯 Purpose

These files are designed for learning and practicing HTML fundamentals. Each file focuses on specific HTML concepts and can be opened in a web browser to see the rendered output.

## 📖 How to Use

1. Open any `.html` file in your web browser
2. View the page in the browser to see how the HTML is rendered
3. Right-click and select "View Page Source" to examine the HTML code
4. Modify the files to practice and experiment with different HTML elements

## 🛠️ Quick Reference

### Common HTML Tags Used
- **Structure**: `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- **Content**: `<h1>-<h6>`, `<p>`, `<div>`, `<span>`, `<main>`, `<article>`, `<section>`
- **Forms**: `<form>`, `<input>`, `<textarea>`, `<select>`, `<button>`, `<label>`
- **Tables**: `<table>`, `<tr>`, `<td>`, `<th>`, `<thead>`, `<tbody>`, `<tfoot>`
- **Lists**: `<ul>`, `<ol>`, `<li>`
- **Navigation**: `<a>`, `<nav>`
- **Media**: `<img>`, `<svg>`

## 📝 Notes

- All files use the standard HTML5 doctype
- Files include proper meta tags for character encoding and viewport settings
- Each file is standalone and can be opened independently
- The images folder contains assets referenced in various HTML files
